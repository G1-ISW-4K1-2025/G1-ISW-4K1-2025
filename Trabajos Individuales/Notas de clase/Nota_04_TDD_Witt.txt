diapo 2 --------------------------------------------------------------------------------------------------------------------------------------------------------------

	Directamente relacionado a una decision cultural
	ACTIVIDADES PARA PUD
	- Esp requerimiento
	- Analisis		} 
	- Diseño			}
	- Implementacion		-> Entre 33% a 35% del costo total del proyecto (horas)
	- Testing / Prueba 	-> Entre el 30% y el 50% del costo total del proyecto (horas). La mas costosa en terminos de esfuerzo (Actividad humano intensiva)
	- Despliegue

	ANTES -> testear luego de tener todo listo
	AHORA -> De forma anticipada planificar, diseñar casos de prueba

	Que es un caso de prueba: 
		Es la identificacion de situaciones concretas mas los datos de seteo necesarios
		para poder determinar si uno o mas criterios de aceptacion se cumplen o no para este software. 
		SETEAR -> precondiciones

diapo 3 --------------------------------------------------------------------------------------------------------------------------------------------------------------

	Falta mucha cultura de testing en las organizaciones
	Creen que es perdida de tiempo

	Si los casos de prueba se crean en base a los requerimientos, ¿por que no hacerlo antes?

	se empezo a proponer la idea de adelantar trabajo del testing.
	Es importante saber como vamos a probar el software que vamos a construir

	Con el agilismo se busca adelantar todo lo que se pueda el pensamiento del testing
	ya cuando llegue la hora del testing, lo unico que queda es lo mas operativo

diapo 11 --------------------------------------------------------------------------------------------------------------------------------------------------------------

	Refactoring
	Forma de desarrollar que apunta a mejorar la calidad interna del componente que se construyo
	- no cambiamos la funcionalidad, solo mejoramos la forma en la que lo hace.
	- Hacer mas eficiente, reducir acoplamiento, aumentar cohesion
